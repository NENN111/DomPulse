# Архитектура

ДомПульс — модульный монолит на FastAPI и SQLite. REST API, публичный Mini App и транспорт MAX используют одно ядро данных. При запуске на VPS Caddy принимает HTTPS-запросы к Mini App, получает и продлевает сертификат ACME и проксирует запросы во внутренний сервис `public-miniapp`; REST API остаётся привязанным к `127.0.0.1`. Входящие события MAX проходят проверку секрета, дедупликацию и транзакционную обработку; ответы записываются в outbox и доставляются отдельно.

Основные модули: `api.py` — REST и авторизация, `max_webhook.py` — диалоги MAX, `polling.py` — локальный транспорт, `outbox.py` — доставка, `sla.py` — SLA первой реакции, `analytics.py` — метрики, `db.py` — схема.

Границы доступа задаются на сервере: житель видит только свои заявки, оператор — заявки назначенных домов и округов. SQLite сериализует записи; переход на PostgreSQL возможен заменой слоя хранения без изменения пользовательских сценариев.
Госуслуги-bridge является внешней границей доверия: он выполняет официальный flow ЕСИА, а backend принимает HMAC-подписанный минимальный адресный claim. Автоматическая привязка разрешена только к существующему дому; неподтверждённый ручной адрес обязательно проверяется одноразовым кодом УК.
