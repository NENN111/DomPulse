# Архитектура

ДомПульс — модульный монолит на FastAPI и SQLite. REST API и транспорт MAX используют одно ядро данных. Входящие события MAX проходят проверку секрета, дедупликацию и транзакционную обработку; ответы записываются в outbox и доставляются отдельно.

Основные модули: `api.py` — REST и авторизация, `max_webhook.py` — диалоги MAX, `polling.py` — локальный транспорт, `outbox.py` — доставка, `sla.py` — SLA первой реакции, `analytics.py` — метрики, `db.py` — схема.

Границы доступа задаются на сервере: житель видит только свои заявки, оператор — заявки своего дома. SQLite сериализует записи; переход на PostgreSQL возможен заменой слоя хранения без изменения пользовательских сценариев.
