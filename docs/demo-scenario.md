# Демонстрационный сценарий

1. Выпустить отдельные коды для жителя и оператора одного дома.
2. Житель вводит `/код …`, создаёт обращение кнопками и подтверждает отправку.
3. Оператор открывает очередь, карточку заявки и отвечает жителю без смены статуса.
4. Оператор принимает заявку, переводит в работу и отмечает выполненной.
5. Житель открывает карточку с историей и подтверждает результат либо возвращает заявку.
6. Два похожих обращения оператор подтверждает как общий инцидент.
7. Третьему жителю бот предлагает присоединиться; связь создаётся только после его явного выбора.
8. Оператор открывает показатели дома и показывает SLA первой реакции.
