# Известные ограничения

- SQLite подходит для хакатонного MVP, но не для большого числа параллельных записей.
- Bearer-токены локального REST API не имеют срока действия и отзыва.
- Нет rate limiting для REST API и полноценной наблюдаемости.
- При сбое после отправки MAX-сообщения, но до фиксации результата возможен повтор.
- Приём фото подготовлен на уровне схемы данных, но выключен до подтверждения входящего контракта MAX.
- Нет production-мигратора схемы и внешней интеграции УК/ГИС ЖКХ.
- Mini App пока не реализован; основной продуктовый сценарий работает в чате MAX.
- Прямая production-интеграция с Госуслугами требует регистрации информационной системы, официальных полномочий ЕСИА и внешнего аттестованного bridge. В репозитории реализованы защищённый callback, выбор адреса и fallback, но реальные реквизиты и OAuth-flow не поставляются.
