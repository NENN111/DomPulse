# Данные и интеграции

SQLite хранит дома, пользователей, заявки, события, привязки MAX, состояния диалогов, входящие обновления, outbox, SLA-уведомления и общие инциденты. `ticket_attachments` подготовлена для метаданных вложений; бинарные файлы не сохраняются.

Реальная интеграция: MAX Bot API по HTTPS, webhook или long polling. Тесты используют `httpx.MockTransport` только как автоматическую проверку контракта. Интеграций с ГИС ЖКХ и внутренними системами УК нет. Seed-данные полностью синтетические.

Официальная документация подтверждает `Message.body.attachments` и тип `image`, но текущий входящий контракт идентификаторов изображения не зафиксирован в проекте достаточно надёжно. Поэтому приём фото выключен до интеграционного теста с реальным событием MAX.
